# Memory v3 · M0 真实 App 验收清单

> 仅用于合并 / 发布前的人工验收。使用专用测试昵称 `Memory M0 QA`，不要在真实用户 scope 中执行删除或清空。

## 准备

1. 从待验收分支构建并运行真实安装包，确认版本和 commit。
2. 新建或选择测试人设卡，昵称设为 `Memory M0 QA`。
3. 打开设置 → 记忆，确认显示 `Memory v3 已就绪`，且在线 / 本地巩固说明与当前文字服务商一致。

## 必测路径

- [ ] **别记这段**：发送“这是合成秘密，别记这段”。用户气泡必须显示“此回合不写入长期记忆”；收起聊天并等待巩固后，记忆页搜索“合成秘密”必须为 0 条。
- [ ] **纠错**：先说“我喜欢辣味”，巩固后再说“更正：最近胃不舒服，不吃辣了”。旧事实必须为 `superseded`，新事实为 `active`；后续相关召回不得使用旧值。
- [ ] **单条删除**：创建一条带唯一关键词的合成事实，在记忆页永久删除并确认；列表、搜索、后续聊天召回均不得再出现。
- [ ] **整卡清空**：在测试 card 下创建 fact、episode、commitment 和 pending job 后执行“清空当前人设全部记忆”；计数、搜索结果和待处理数必须全部归零，其他 card 不受影响。
- [ ] **退出 / 重启恢复**：发送合成信息后立即收起并退出；重新启动后 pending job 必须继续处理，最终生成记忆且原始 job payload 被清除。
- [ ] **无 Key 恢复**：暂时移走 DeepSeek Key 后产生待巩固批次；聊天会按其自身 provider 能力提示错误，但 Memory 失败不得导致窗口卡死或退出受阻。恢复 Key 并保存后，job 应立即重试并完成。
- [ ] **本地模型不可用**：选择本地文字 provider，并使用未安装模型或停止 Ollama；Memory 显示可见错误且保留 job。恢复 Ollama / 模型后保存设置，job 应完成。
- [ ] **数据库暂时不可用**：仅在测试数据库副本或调试环境锁库；文字聊天继续走最近对话 + 滚动摘要，解锁后 job 自动恢复。不得对真实数据库做破坏性故障注入。

## 收尾

1. 清空测试 card / `Memory M0 QA` scope，确认 facts、episodes、commitments、jobs 和 FTS 均为 0。
2. 恢复原文字 provider、Key、模型、昵称、人设卡和窗口设置。
3. 在 [`roadmap-memory-brain.md`](./roadmap-memory-brain.md) 记录应用版本、commit、平台和结果；未实际执行的项不得勾选。
