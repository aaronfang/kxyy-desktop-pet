# v0.2.57 发布说明

本次整合 v0.2.52 之后的本地迭代，包含 QQ 语音与实验性电话、自然交流、时间记忆、搜索资料卡及共同观看改进。v0.2.53–v0.2.56 为本地迭代版本。

## QQ 连接与多媒体

- 在设置中启动/关闭 QQ 自动回复，自动管理本机 QQ/NapCat 连接；需要登录时显示二维码。默认只处理绑定主人的私聊。
- 可选择文字或语音回复，支持主人语音转写；人格、昵称和长期记忆与桌宠共用。
- 支持图片/图文识别、QQ 内置表情名称理解及允许列表中的表情/表情包发送。语音模式下表情单独发送；GIF 只理解首帧，视频理解暂未实现。
- macOS 实验性 QQ 电话支持接听、流式回复、打断和挂断；依赖外部 KoishiRTC、BlackHole 2ch/16ch 和本地语音环境，不随本安装包自动安装。

## 自然交流与时间记忆

- 支持连续短消息合并、按完整意思分段，以及一次有新内容的同话题补充。
- 可根据明确兴趣、缓存资讯、近期经历和待跟进约定主动分享；提供自然/更主动模式、静默时段、暂停/恢复和可选每日联系目标。
- 设置显示主动交流决策、下一检查时间、兴趣缓存和活动进度；科学、工作成长等可选兴趣类别也能进入主动分享评估。每日联系仍遵守静默、闲置和联系预算，不保证强制每日发信。
- 保存原消息日期，区分过去事件、当前状态与未来计划，减少旧记忆被当成当前话题；多日期/时态无法消歧时不猜。
- 减少同来源事实与经历的重复召回；电话按回合聚合已完成播放的内容，跨语音消息/电话复用记忆。

## 按需搜索与资料卡

- 不要求固定搜索触发词；明确公开搜索直接执行，公共资讯在判断失败时有兜底。
- DeepSeek Search 与 Tavily 使用本机密钥回退，不受人格模式、聊天模型或兴趣缓存开关限制。
- 提取有界正文摘录、去重并优先相关技术/论文/项目来源；资料不足最多补搜一轮，全部检索共享24秒期限。
- 搜索回答先给简短语音概括，再发送文字细节和真实来源链接，标注可用发布时间与“页面正文摘录/仅摘要”。文字模式也分开概括和资料。
- 搜索资料不进入长期记忆；后续文字失败不重发已确认语音，新消息取消旧回复余段。

## 其他累积改进

- 共同观看支持更完整的视觉上下文、主体识别、基于真实证据的主动评论和结构化回顾。
- 增加聊天/记忆导出、熟悉度与心情展示，并修复本地实时语音首轮稳定性及相关跨平台测试。

## 验证与限制

- 本机完整自动化门禁涵盖 JS、Python、资源合同、Rust 测试和编译检查；具体最终结果见发布 PR。
- 用户已确认 QQ 语音收发、电话提速/打断、语音保存后电话回忆、图片和表情交互。
- macOS 隔离真实 Tauri/WebView 配合模拟 OneBot 验证了分段、取消、搜索资料发送和失败回退；真实服务与模型验证了搜索正文和资料卡生成。
- 新资料卡在真实 QQ 客户端的最终显示/播放、跨夜自然交流和 Windows/Linux 原生电话尚未完成真人验收。Windows/macOS CI 的自动检查与构建不能代替设备、账号和听感验收。
- 原生电话为 macOS 实验功能，其他平台不要据此假定可用。搜索正文可能缺失，发布时间可能未知，页面摘录不代表已阅读整篇论文/PDF。
- macOS 沿用现有未签名/未公证分发方式。
