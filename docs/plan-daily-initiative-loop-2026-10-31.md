# 主动交流每日循环：实施与验收

Goal：补齐授权缓存后台更新、主动候选池、可选每日联系目标和诊断。仅本地修改，不提交/推送。

## 验收条件与边界

1. 缓存开启且来源到期时后台刷新；关闭后不启动新请求。失败按来源指数退避，成功重置，手动刷新仍有最短间隔。后台不发送聊天、人格或 Memory；只访问已有固定来源。用受控时钟和源适配器验证到期、失败、恢复和重启。
2. 普通聊天仍最多三条；主动路径独立检查最多200条本机缓存，先过滤六小时时效、兴趣、敏感和使用/放弃/延迟，再跨分类选择有界候选。测试前三条被排除仍能找到后续资料、分类轮换及失效边界。
3. 每日目标默认关闭，可选开启并保存。北京时间18点起（受静默和已有闲置/间隔约束）当天未确认长时联系时准备一次；资料/记忆优先，无可用来源时只提出基于已保存兴趣或普通陪伴的轻量话题，不伪造资讯/主人消息/生活经历。每日最多两次目标决策，未知发送不自动补发；真正确认的长时联系才满足目标。暂停、静默、切身份、关闭、通话优先。重启/跨日按scope隔离。
4. 设置区分缓存关闭/无兴趣/过期/来源用完/评估额度/补充中/失败退避/模型等待，显示后台刷新与每日目标状态/时间。诊断无内容正文/凭据。
5. 保持语音/独立表情互斥、电话规则和确认前缀记忆；外部资料与每日控制提示不进入用户 Memory。

## 验证顺序

按垂直 Red→Green 开发；执行受影响 JS/Rust→完整 npm run test:gate→macOS独立Tauri/WKWebView＋模拟OneBot；最后恢复正常开发版。真实QQ自然度、语音听感、整日/跨夜和其他平台单列未验收，不替代为模拟通过。
