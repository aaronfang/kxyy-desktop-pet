# QQ 自然互动：自动验收与剩余手测

日期：2026-10-31，北京时间。仅本地修改，未提交/推送。没有向真人 QQ 发送测试消息。

## 本轮改动

- 设置 → QQ 接入增加“主动交流状态”：原生已保存模式/通道、当日长时联系预留次数、固定阻塞原因、最早再次评估日期时间/约剩余分钟、24 条固定决策、兴趣缓存摘要、分类小目标进度。
- 缓存摘要采用已保存设置和实际本机缓存，区分未开启、无“感兴趣”分类和没有六小时内有效兴趣资料；只返回布尔、计数和时间，不增加网络请求或导出来源正文。
- 提供直达“时下信息”和“人设 → 话题偏好”的按钮，明确缓存与搜索、普通聊天参与频率与 QQ 主动频率的关系。
- 跨日的“今日联系预留”不再显示昨天的次数；其防重预算规则不变。
- 只读确认本机已有观察开关开启、4 个感兴趣分类、107 条缓存；没有替用户改动开关或偏好。缓存数量是检查时快照，后续刷新可能变化。

## 仍需用户手动的最小验收

| 项目 | 操作 | 完成条件 |
|---|---|---|
| 真实 QQ 语音与表情 | 发一句文字、一条语音、请求独立表情 | 语音可播放、转写语义正确；表情可见；不出现语音表情混发、漏回复或重复回复 |
| 真实电话回归 | 拨入、交谈两句、说话打断后挂断 | 自动接听，双向声音连续，打断和挂断正常；新功能没有破坏原通话 |
| 模型自然度 | 正常聊几个开放话题，适当留白，不固定每轮追问 | 能观察到有理由的展开/偶尔续话；不过度反问、重复或催促。若一直选择等待，提供时间点即可结合固定决策调查 |
| 长时主动与跨夜 | 保持运行，观察一天并覆盖一次静默时段 | 有资料/真实约定时择机联系；静默不打扰；昨天事件不当今天；不回应后温和退避 |
| 真实退出和重开 | 无通话时通过托盘退出，再正常启动；关闭/开启 QQ 开关 | 托管服务按设计结束并恢复，只有一个正常桌宠实例；无残留、重复连接或旧草稿补发。此项未用模拟服务替代验收 |
| 其他平台与安装包 | 有对应设备/安装包后执行上述核心流程 | 在对应环境单独通过；本机开发版通过不替代其他平台 |

只需给异常的发生时间、模式、设置中的原因及看到/听到的现象；不必导出私人聊天或完整记忆。暂不要求重复执行已通过的模拟协议测试。
