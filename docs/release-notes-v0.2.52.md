# v0.2.52 发布说明

## 网络信息搜索

- 文字聊天和本地/CosyVoice/VoxCPM 实时通话支持明确的互联网搜索请求。
- `你知道……`、`知不知道……`、`看没看过……` 等语义知识问题可进入信息核验流程。
- `查一下`、`搜索`、`搜一搜`、`找一下`、`重新搜索` 等明确指令会优先执行 Tavily 网络搜索。
- “这部剧”“那一部”“刚才说的那一部”等上下文指代会保留最近提到的片名，避免产生无主题查询。
- 没有可验证来源时，模型必须说明未知或搜索失败，不得补写评分、剧情、演员或上映日期。

## 实时通话

- 实时会话协商 `web-observation-v1` 后，搜索结果通过当前回合上下文注入模型。
- 搜索上下文等待上限为 6 秒，覆盖本地代理发起 Tavily 请求的 5 秒超时，避免模型抢先生成“没有联网”。
- 明确搜索请求会先提示“我去查一下，马上回来。”，搜索完成后再生成正式回复。

## Debug 与验证

开启聊天 Debug 后，底部会显示搜索阶段、来源、结果数和耗时，例如：

```text
搜索 已找到 · 网络 Tavily · 3 条 · 2.4s
```

本版本已验证 JS、Python、资源契约和 Rust 检查；实时语音的麦克风、扬声器和各平台打包仍需按 [实时设备验收](realtime-device-acceptance.md) 执行实机验收。
