# 记忆与 QQ 能力迭代计划（2026-10-29）

范围：记忆准入与同源召回、电话回合聚合、DeepSeek 搜索、QQ 双向表情、图片／图文。视频不在本轮范围。修改保留本地，不提交／推送。

## 验收与实施顺序

1. 记忆：事实可单独保存，无独立背景的经历不硬凑；事实查询优先同源事实，经历查询保留事件背景；电话只聚合已完成播放片段，同一用户陈述只出现一次，重复／隐私／删除边界有效。
2. 搜索：增加 DeepSeek adapter，复用当前 Key；QQ 明确搜索返回真实资料与来源；失败不假装联网；取消、设置切换有效；网页和派生回答不写入长期记忆／后续模型历史。
3. QQ 消息：接受文字、内置表情、图片及混合段；先验证绑定身份再获取媒体；最多有限张图、固定格式／字节／解码尺寸；不接受任意远端 URL、本地路径。视频等未支持类型有明确说明。
4. 回复：人格和昵称继续跟随桌宠设置；角色可使用项目允许列表的表情包；文字模式可附表情，语音模式仅发语音或单独表情；实际成功发送才进入记忆整理。图片观察与用户陈述分离，禁止把视觉推测当作用户事实。
5. 验证：每个行为先 Red 再 Green；公开 JS 管线、Rust 持久化与回环 HTTP／WS 合同测试；最终完整 test:gate。可用的 macOS App 验收如实记录；Windows 与需要主人发消息的验收标明依赖，不伪造通过。

### 已实现

- Memory：新增独立经历背景准入；普通事实召回同源去重、经历查询保留背景；不修改历史数据。电话按 session/generation 聚合已播放片段，一次用户陈述、重复片段幂等，回合完成／打断／挂断推进任务，保留5分钟崩溃恢复兜底。
- 搜索：DeepSeek 固定 Tools Search adapter，复用本机 Key，最多128字／4条摘要，4秒／256KiB 上限；Tavily 保留。桌宠复用既有观察合同，QQ 明确搜索附最多两条来源，整轮不入后续 QQ 历史和长期记忆。取消后的迟到响应丢弃。
- QQ：文字／face／image 混合消息；重读原始消息验证主人和消息 ID，再凭不透明 token 读取 QQ 下载文件；固定路径、类型、大小及解码限额；图片沿用当前视觉设置与人格召回；读取／模型失败有明确回复。
- 输出：固定 QQ 表情／元元内置表情包允许列表；文字模式附表情，语音与单独表情互斥；陌生人、人设切换、Memory lease 边界继续有效。图片中的明确保存请求提示另发文字，避免虚假保存回执。
- 记忆隔离：图像、表情标签、角色视觉推测不入长期证据，仅允许用户真实文字；搜索派生问答不入长期证据。未合并元宝与旧昵称。

## QQ 语义自动搜索与官方接口核对（2026-10-29）

用户确认天气请求已返回检索资料，并要求不依赖“查一下”等触发词。按用户提供的[中文官方指南](https://api-docs.deepseek.com/zh-cn/guides/search)核对：DeepSeek适配器使用相同的独立Search接口；没有迁移到Responses内置搜索。继续保留用户当前Tavily选择。

### 行为与边界

- QQ文字与主人语音转写接入`planWebSearch`。明确搜索直达原适配器；隐式问题由当前文字模型做一次只读判断，结构化输出`search/query`，无需固定触发词。天气、近期推荐、开放时间、陌生作品可搜索；闲聊、创作、常识和私人记忆不搜索；明确“不联网”、显式保存、敏感信息及纯图片／表情绕过规划。
- 规划最多2.5秒，只带当前问题和应用提供的北京时间日期，没有人设、昵称、画像、历史或Memory。异常、取消、畸形／过长查询失败关闭，不重试、不启动过期检索。每轮最多一次查询，必要搜索词最多128字；语义查询可绕过旧关键词预筛，搜索服务仍为保存的DeepSeek或Tavily。
- 自动规划会增加一次短模型请求；显式搜索跳过这个开销。天气显式查询中的相对日期转为具体日期；作品标题保持原文，避免把《明天会更好》改成日期。模型规划也得到真实日期，但这不等于已实现天气来源准确率或网页时间相关性排序。
- JS短历史排除与Rust发送回执同步：发送元数据只可增加记忆排除，不能绕过已有隐私、来源或lease检查。成功、无结果及搜索失败的问答均不进长期记忆或后续QQ历史。
- 当前只更新QQ文字／语音消息策略，桌宠其他渠道、QQ电话的搜索策略保持原边界。没有增加自动抓取全文、任意URL访问或无人发问时的主动搜索。
