# Domain docs

This repository uses a single-context domain-document layout.

Before changing a domain area, read the root `CONTEXT.md` when it exists and any relevant decisions under `docs/adr/`. Missing files do not block work; create or extend them only when a durable term or hard-to-reverse decision needs recording.

Use the glossary's established terms in specs, tickets, tests, and implementation. Surface conflicts with an existing ADR explicitly instead of silently overriding it.
